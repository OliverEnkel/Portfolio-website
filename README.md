# Portfolio Website

Dieses Projekt ist eine einfache Portfolio-Website, die ich erstellt habe,
um meine Grundlagen in HTML, CSS und JavaScript praktisch anzuwenden.

Die Website dient als persönliche Vorstellung und enthält eine Übersicht
meiner IT-Kenntnisse sowie einen Link zu meinem Lebenslauf als PDF.

## Verwendete Technologien
- HTML
- CSS
- JavaScript

## Funktionen
- Übersichtliche Card-Struktur
- Responsives Layout
- Lebenslauf als PDF direkt über die Website abrufbar
- Einfache JavaScript-Funktionen (z. B. Anzeigen der E-Mail-Adresse)

## Ziel des Projekts
Ziel war es, eine saubere und übersichtliche Website ohne Frameworks zu erstellen,
um die Grundlagen der Webentwicklung besser zu verstehen.

## Projekt starten
Die Website kann direkt über die `index.html` im Browser geöffnet werden.
